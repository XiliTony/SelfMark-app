# 切片 08：插件市场集成测试——端到端闭环 + 跨用户隔离

**类型**: AFK
**覆盖用户故事**: 全部（demo 验收路径）

## 构建内容

用 SpringBootTest + Testcontainers（MySQL 8 + Redis）补齐关键路径集成测试，作为 demo 版插件市场的验收脚本。本切片不写新业务代码，只写集成测试（若暴露缺陷则顺带修复）。

测试数据：Plugin seed 与生产共用同一套 seed 机制；用户数据每个用例自行注册。

## 验收标准

- [ ] 端到端闭环：注册 → 登录 → 拉市场（恰好见画板+番茄钟，均未安装）→ 安装画板（返回默认四象限配置）→ 修改象限名称 → 再拉市场验证持久化 → 禁用 → 启用（config 原样）→ 卸载 → 市场恢复未安装状态
- [ ] 番茄钟路径：安装 → 默认 label="专注" → 改 label → 再拉市场验证持久化
- [ ] 跨用户隔离：用户 A 安装插件后，用户 B 的市场列表仍显示未安装；B 操作 A 的实例（改配置/启停/卸载）均返回 403
- [ ] seed 幂等：测试上下文重建后 plugin 表不产生重复插件
- [ ] 全量测试（MockMvc + Service 单测 + 本集成测试）一次通过
